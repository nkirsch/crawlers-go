# crawlers-go

Public Go library (`crawlers.go`, `ranges.go`) that classifies web visitors
as crawlers or people. Shared by private visitor reports and the auto-builder
hubs' `/visitors`. Stdlib only, go 1.26.

- Public repo: only generic rules and public data. No site names, owner
  IPs, watched networks, identities or example IPs from real logs; tests use
  `example.com` and documentation ranges (203.0.113.0/24, 2001:db8::/32).
  Site-specific rules stay in each app, via `Rules.Extra` and `Rules.Page`.
- `ranges.txt` (provider<TAB>prefix) and `tor.txt` are generated by
  `go run ./cmd/ranges` (published lists, geofeeds, RIPEstat announced
  prefixes, the Tor bulk exit list). `refresh.yml` reruns it on the 1st of
  each month and opens a PR; merging it should be followed by a tag.
- Checks: `gofmt -l .`, `go vet ./...`, `go test ./...`. Releases are semver
  tags (`v0.x.y`); dependents bump with `go get github.com/nkirsch/crawlers-go@latest`.
